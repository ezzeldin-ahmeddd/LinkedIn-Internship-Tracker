# LinkedIn-Internship-Tracker
Desktop internship tracker with LinkedIn scraping, CS job filtering, and application management.
this is a homemade custom app i made to help me track new jobs that get posted, and help me keep in track of jobs i applied to.
Features:
- LinkedIn intership scraping
- CS internship filtering
- Apply tracking
- Applied jobs page
- CSV export
- Clickable job links
- Sidebar navigation
Tech Stack Used:
  - Python
  - Requests
  - BeuatifulSoup
  - CustomTkinter
